## Что изменит числа, когда доделаем

Чтобы потом было понятно, почему прогон 2 не совпадёт с прогоном 1:

| что меняем | как подействует на `Cov_T` |
|---|---|
| пешеходный граф вместо прямой | **снизит**: по сети всегда дальше, чем по прямой |
| настоящая гос-сеть вместо прокси по названию | непредсказуемо: сеть может оказаться и больше, и меньше 40 |
| сетка в UTM вместо градусов | слабо, но сместит границы клеток и `cell_id` |
| площадки по долям площади полигонов | изменит число допустимых клеток (сейчас 72) |
| GHS-POP/WorldPop вместо Kontur | сместит `P_i`, значит и все взвешенные метрики |
| привязка к графу, `snap_max_m = 300` | появятся недостижимые клетки — сейчас их нет вовсе |
| `t_max = 60` | сейчас не достигается: максимум 27,7 мин |

Главный из них — первый. Все `Cov_T` в прогоне 1 **завышены**.
